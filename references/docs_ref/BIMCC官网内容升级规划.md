## 1. 改版核心判断

当前官网已经具备“首页 + 产品与服务 + 解决方案 + 客户案例 + 公司动态 + 荣誉资质 + 联系我们”的基本结构，但宣传册中更完整的能力体系、行业矩阵、案例资产和资质背书尚未被组织成清晰的转化路径。

建议将官网从“产品资料展示型网站”升级为：

> 面向建设单位、施工总包、全咨/监理、政府监管、产业园区与高校客户的“一体化数字建设解决方案官网”。

新版官网需要讲清楚四件事：

1. 筑云是谁：深耕 AEC 行业的一体化数字建设解决方案服务商。
2. 凭什么做：飞椽 Fyra 零代码开发平台 + BIMCC 智能建造平台 + BIM/GIS/UE/3DGS/AI/IoT 多技术融合能力。
3. 能解决什么：企业级、行业级、项目级数字建造与智慧运维问题。
4. 为什么可信：1000+ 项目、国央企/政府监管客户、行业奖项、专利软著、典型案例和区域服务能力。

## 4. 首页模块规划

### 模块 1：首屏 Hero

目标：3 秒内讲清“筑云做什么、有什么底座、服务谁”。

内容：
- 主张：一体化数字建设解决方案服务商
- 技术底座：飞椽 Fyra + BIMCC 智能建造平台
- 能力关键词：BIM / GIS / 物联网 / AI / 数字孪生 / 零代码
- 数据背书：80% 大型国央企/政府监管客户、1000+ 重点项目、80+ 专利软著、100+ 国家级/省部级奖项
- CTA：预约咨询、查看案例

展示建议：
- 使用工程数字孪生大屏、项目驾驶舱或平台界面截图作为主视觉。
- 避免只放抽象科技背景；B2B 工程客户更需要看到真实系统、真实场景和真实案例。

### 模块 2：客户痛点 / 业务场景

目标：把访客从“看公司介绍”拉到“这正是我的问题”。

可分为 6 个痛点：
- 多系统割裂：OA、ERP、智慧工地、BIM 平台数据不通。
- 项企协同弱：集团、分公司、项目、工点之间难以联动。
- 项目监管难：进度、质量、安全、成本、物资设备不能实时闭环。
- 定制开发慢：工程企业需求个性化强，传统开发成本高、周期长。
- 数据资产难沉淀：过程资料、模型数据、物联数据无法复用。
- 运维交付断层：施工阶段数据不能平滑进入运维管理。

### 模块 3：筑云一体化能力地图

建议用“三层架构”组织官网核心叙事：

| 层级 | 官网表达 | 对应内容 |
|---|---|---|
| 技术底座层 | 飞椽 Fyra 数智捷构基座 | 零代码、页面/表单/流程/报表/大屏/APP/H5、数据中台、物联网中台、AI 算法中台 |
| 业务平台层 | BIMCC 智能建造平台 | 协同办公、设计管控、质量、安全、进度、成本、物资设备、数字档案、BIMGIS 一张图 |
| 服务交付层 | 全生命周期数字建设服务 | 智慧工地、BIM 咨询、数字孪生运维、工程 XR、展厅指挥中心、数字教育、创新技术服务 |

### 模块 4：核心产品平台

首页只放 4-6 个主卡片，不把所有服务堆在首屏。

推荐卡片：
1. 飞椽 Fyra 智能开发平台
   - 关键词：AI 赋能、零代码、工程行业模板、敏捷交付
   - 链接：了解飞椽平台
2. BIMCC 智能建造平台
   - 关键词：BIM+GIS+UE+3DGS，多端协同，十大管理系统
   - 链接：查看平台架构
3. 智慧工地建设
   - 关键词：设备接入、现场监管、智慧工地平台对接
   - 链接：查看智慧工地案例
4. 数字孪生 / 智慧运维
   - 关键词：实时监测、智能预警、协同处置、运维驾驶舱
   - 链接：查看运维方案
5. BIM 咨询与工程数字技术
   - 关键词：全过程 BIM、无人机、三维扫描、3DGS、BIMVR
   - 链接：查看技术服务
6. 数字化教育体系
   - 关键词：课程资源、实训平台、BIMVR/AR/MR 实训室、校企合作
   - 链接：查看教育方案

### 模块 5：按客户角色进入解决方案

目标：让不同客户快速找到自己。

卡片：
- 建设单位：全生命周期项目监管与数字化交付
- 施工单位：项目履约、质量安全、进度成本一体化管理
- 全咨 / 监理：多方协同、过程留痕与数字化咨询服务
- 政府 / 集团监管：区域项目一张图监管与数据驾驶舱
- 教育 / 医疗：基建数字化管理与智能建造教学体系
- 企业数字化：零代码平台赋能企业运营与数字化转型

### 模块 6：按行业场景进入解决方案

推荐行业分组：
- 房建
- 民航机场
- 轨道交通 / 铁路
- 市政道路 / 高速公路
- 水利水务 / 水运 / 抽水蓄能
- 隧洞 / 地下工程
- 医院 / 文体教育 / 科研办公
- 企业园区 / 运维资产

每个行业卡片只回答三件事：
- 典型问题
- 解决方案组合
- 对应案例

### 模块 7：技术优势

推荐标题：

> 从模型可视化，到业务数据闭环

技术亮点：
- BIM + GIS + UE + 3DGS 多引擎融合
- 业务功能可脱离 BIM 独立运行，适配不同项目数字化成熟度
- 飞椽云敏捷交付模式
- 应用模板库与行业规则沉淀
- 工程 AI 与智能体应用
- 多端应用：PC / H5 / APP / Win / Mac / BI 大屏
- 开放集成：OA / ERP / 智慧工地 / IoT / 数据中台

### 模块 8：案例与业绩

首页建议展示“精选案例 + 行业筛选入口”，而不是长列表。

首页精选案例：
- 企业级：重庆机电控股集团企业级 BIM 施工管理平台
- 企业级：重庆建工集团工程质量企业智慧监管平台
- 企业级：海南交投数智建管平台
- 基建：重庆轨道交通 15 号线 BIM+智慧工地建管平台
- 机场：南宁吴圩国际机场 T3 航站区及配套设施建设工程
- 水利水电：永安抽蓄智慧工地平台
- 教育：重庆工商职业学院数字基建管理平台
- 运维：呈贡文体活动中心智慧运维平台

每个案例卡片建议包含：
- 客户 / 项目名称
- 行业类型
- 使用产品或服务
- 解决的问题
- 交付成果
- 可量化结果或奖项背书

### 模块 9：资质荣誉与信任背书

内容拆成三类：
- 企业资质：高新技术企业、专精特新、CMMI、ISO、信息系统服务交付能力等
- 技术资产：专利、软著、标准规范、国产化兼容认证
- 行业荣誉：龙图杯、创新杯、工程建设行业 BIM 大赛等

首页只展示代表性图标，详情进入“荣誉资质”页面。

### 模块 10：合作伙伴

不要只做 logo 墙。建议按类型分组：
- 建设 / 施工 / 业主客户
- 行业生态伙伴
- IT 与国产化生态伙伴
- 高校 / 研究机构

### 模块 11：洞察与动态

当前官网已有公司动态，但建议从“新闻列表”升级为“行业洞察 + 产品动态 + 案例实践”。

栏目：
- 行业观察：智能建造、AI 安全管理、数字孪生趋势
- 产品动态：飞椽、AI 班前会、土石方智控等
- 案例实践：项目复盘、获奖案例、交付方法
- 公司新闻：参展、荣誉、合作

### 模块 12：底部转化区

建议固定出现：
- 一句话 CTA：让你的下一个工程项目，拥有统一的数据底座和可视化管理能力
- 按需求咨询：企业平台 / 项目平台 / 智慧工地 / BIM 咨询 / 数字孪生 / 教育体系
- 联系方式：电话、微信、分支机构
- 快速入口：产品、解决方案、案例、荣誉、关于

## 5. 二级页面结构

### 5.1 产品平台页

每个产品页统一采用以下模板：

1. 页面首屏
   - 产品定位
   - 适用客户
   - 解决问题
   - CTA
2. 产品能力总览
   - 用 1 张架构图说明能力边界
3. 核心模块
   - 每个模块讲“功能 + 使用场景 + 价值”
4. 技术差异化
   - 不只讲技术名词，要解释对客户的业务价值
5. 典型应用场景
   - 按客户/行业/阶段组织
6. 案例证明
   - 关联 3-6 个案例
7. 交付方式
   - 标准版 / 定制化 / 私有化 / 集成对接 / 培训运维
8. 常见问题
   - 是否能对接现有系统
   - 是否必须有 BIM 模型
   - 项目多久能上线
   - 是否支持国产化环境

### 5.2 飞椽 Fyra 页面重点

建议从“零代码是什么”升级为“工程行业数字化开发底座”。

页面核心信息：
- 工程行业零代码，不是通用低代码工具。
- 内置行业规范、业务模板、数据中台、物联网中台、AI 算法中台。
- 可构建页面、表单、流程、报表、大屏、工作台、APP/H5、设备组态等。
- 支撑企业级平台、项目级平台、数字孪生与智慧工地的快速交付。
- 降低重复数字化投入和第三方绑定风险。

### 5.3 BIMCC 智能建造平台页面重点

页面核心信息：
- 以管理为核心、以 BIM 模型为载体、以物联网设备为触手。
- 融合工程业务数据、模型数据、物联数据。
- 覆盖工程协同、前期、进度、成本、物资设备、质量、安全、智慧物联、BIMGIS 可视化、运维等场景。
- 支持企业-项目-工点多层级联动。

### 5.4 解决方案页

解决方案页不要重复产品页。它要从客户任务出发。

统一模板：

1. 适用对象
2. 业务痛点
3. 解决方案架构
4. 推荐产品组合
5. 典型流程
6. 交付成果
7. 相关案例
8. 咨询 CTA

示例：施工单位解决方案
- 痛点：项目多、标准难统一、安全质量风险高、数据上报重复。
- 方案：BIMCC 平台 + 智慧工地 + 物联网设备 + 飞椽定制化。
- 成果：项目履约看板、质量安全闭环、进度计划对比、成本物资联动、数字档案。

### 5.5 客户案例页

建议把客户案例做成“可筛选案例库”，筛选维度如下：

| 维度 | 选项 |
|---|---|
| 行业 | 房建、医院、文体教育、机场、科研办公、水利水电、轨道交通、市政道路、高速公路、海外 |
| 客户类型 | 建设单位、施工总包、全咨/监理、政府监管、院校、运营单位 |
| 产品服务 | 智能建造平台、智慧工地、BIM 咨询、数字孪生、BIMVR、展厅指挥中心、数字教育 |
| 项目层级 | 企业级、项目级、行业级、专项服务 |

案例详情页模板：

1. 项目背景
2. 客户挑战
3. 筑云方案
4. 应用模块
5. 交付成果
6. 可量化价值
7. 项目截图 / 平台界面 / 现场图
8. 关联解决方案

## 8. 首页信息流推荐顺序

首页不建议连续堆叠 13 个大板块。13 项可保留为内容池，但首页主叙事应压缩为 8 个模块，形成更清晰的访客决策路径。

1. 首屏 Hero + 核心数字背书：定位、技术底座、转化按钮、客户结构、项目数、奖项专利
2. 客户痛点 + 筑云解法：系统割裂、监管难、定制慢、数据断层，对应一体化数字建设方案
3. 一体化能力地图：飞椽 Fyra 底座 + BIMCC 智能建造平台 + 全生命周期服务
4. 核心产品平台：飞椽、智能建造平台、智慧工地、数字孪生、BIM 咨询、数字化教育等主产品入口
5. 解决方案入口：客户角色与行业场景合并为 Tab 模块，减少首页长度
6. 技术与交付优势：多引擎、AI、IoT、模板库、敏捷交付、开放集成、国产化兼容
7. 精选案例：按行业展示 6-8 个代表案例，更多进入案例库
8. 信任背书 + 转化 CTA：荣誉资质、合作伙伴、联系方式与咨询入口合并收口

被合并或下沉的内容：
- 指标背书并入首屏，不单独占一屏。
- 客户角色解决方案与行业场景解决方案合并为一个 Tab 模块。
- 荣誉资质与合作伙伴合并为“信任背书”。
- 行业洞察 / 新闻不作为首页主流程，只保留底部轻量入口。
- 预约咨询 CTA 不单独做大板块，而是在首屏、案例后、页尾重复出现。

## 11. 需要统一的内容口径

官网改版前建议先确认以下口径：

1. 公司成立年份、发展阶段与“11 年经验”的表述。
2. 项目数量：官网与宣传册均强调 1000+，建议保留。

6. 产品命名：飞椽 Fyra、BIMCC 智能建造平台、累土智控、AI 班前会等产品名需统一中英文与大小写。
