## 1. 关于视觉参考的建议

视觉方向参考可以晚些再给，不影响当前继续推进内容、结构和版式策略。

但建议在进入“首页视觉稿 / 前端实现 / 设计系统定稿”之前提供，效果会更准。最好给 3-5 个参考，并说明每个参考喜欢什么、不喜欢什么：

- 喜欢的官网或页面链接
- 喜欢的局部截图，如首屏、导航、案例卡片、产品架构图、联系表单
- 明确不想要的风格，如过度蓝色科技风、过度政府门户风、过度 SaaS 模板感
- 公司已有品牌资料，如 Logo 源文件、VI 色值、产品截图、项目现场图、平台大屏图
- 希望对标的对象，如智能建造公司、BIM 平台、工业软件、建筑科技企业或数字孪生平台

如果暂时没有参考，可以先按本稿默认方向推进：工程可信、平台专业、真实场景、克制科技感。

## 2. 推荐视觉总方向

### 方向名称

```text
工程级数字底座：可信、清晰、可落地的智能建造科技感
```

### 设计关键词

```text
专业可信 / 工程现场 / 数字驾驶舱 / 平台化能力 / 数据联动 / 稳重科技 / 国产化适配 / 长期服务
```

### 视觉判断

筑云官网不适合做成泛科技公司的抽象炫酷风，也不适合做成传统工程公司的厚重宣传册风。更合适的方向是：

> 用真实平台界面和工程场景建立可信度，用清晰的信息层级组织复杂能力，用适度的数字孪生视觉表现技术领先。

## 3. 三个可选视觉路线

### 路线 A：平台驾驶舱型，推荐

适合目标：
- 强调 BIMCC 智能建造平台、飞椽 Fyra、数据中台、项目一张图。
- 面向建设单位、施工总包、集团监管、政府监管等决策客户。

视觉特点：
- 首屏使用平台驾驶舱、BIM+GIS 一张图或数字孪生大屏。
- 页面色彩以深蓝、白、浅灰、科技青为主，但控制蓝色面积，避免模板化。
- 模块排版偏产品化，突出架构图、功能卡片、数据看板和案例证据。

优点：
- 信任感强，容易解释复杂业务。
- 最适合把“平台 + 解决方案 + 案例”组织成销售转化路径。

风险：
- 如果没有高质量产品截图，容易显得空泛。

素材需求：
- 平台首页 / 大屏 / BIM+GIS 界面截图
- 智慧工地现场图
- 数字孪生运维看板
- 典型项目照片或案例封面

### 路线 B：工程现场型

适合目标：
- 强调公司深耕工程行业、案例多、交付强。
- 面向项目业主、施工企业、现场管理人员和区域市场客户。

视觉特点：
- 首屏以真实工程项目、现场设备、指挥中心、展厅大屏为主视觉。
- 数字界面作为叠层或局部浮窗出现。
- 文案更接近“项目管理提升”和“工程现场可落地”。

优点：
- 更接地气，容易让工程客户相信不是单纯软件公司。
- 适合展示 1000+ 项目经验和智慧工地能力。

风险：
- 如果现场图质量参差不齐，整体高级感会被拉低。

素材需求：
- 高质量项目现场图
- 智慧工地设备图
- 指挥中心 / 展厅 / 观摩会照片
- 施工现场 + 平台界面的组合图

### 路线 C：研发底座型

适合目标：
- 强调飞椽 Fyra、零代码、AI、引擎、中台、国产化生态。
- 面向企业数字化负责人、技术负责人、软件合作伙伴。

视觉特点：
- 首屏强调“技术底座”和“能力引擎”。
- 使用架构图、节点网络、低代码构建器、组件化界面。
- 页面更像工业软件 / 企业软件官网。

优点：
- 能凸显筑云自研能力，避免被理解成项目外包服务商。
- 适合后续独立建设产品官网或飞椽专题页。

风险：
- 对非技术型客户不够直观，工程场景说服力会弱一些。

素材需求：
- 飞椽编辑器截图
- 表单 / 流程 / 大屏 / APP/H5 构建界面
- 技术架构图
- AI 应用与智能体操作界面

## 4. 推荐组合方案

建议首页采用“路线 A 为主，路线 B 与 C 辅助”的组合：

1. 首屏：平台驾驶舱型，建立数字化与平台化第一印象。
2. 痛点与解法：用工程现场语言，避免纯技术话术。
3. 能力地图：用研发底座型表达飞椽 Fyra、BIMCC、多引擎与中台能力。
4. 产品平台：偏企业软件官网，卡片清晰、信息密度适中。
5. 解决方案：偏行业咨询官网，强调客户角色和行业场景。
6. 案例模块：偏工程现场型，用真实项目增强信任。
7. 信任背书：偏机构与资质展示，稳重克制，不做证书墙堆砌。

## 5. 首页版式策略

### 顶部导航

推荐：

```text
Logo / 首页 / 产品平台 / 解决方案 / 客户案例 / 技术与研发 / 资源中心 / 关于筑云 / 联系我们 / 预约咨询
```

策略：
- “首页”保留在顶部导航，符合企业官网浏览习惯。
- “预约咨询”作为右侧按钮，不放进普通导航项。
- 产品平台、解决方案、客户案例建议做下拉或 Mega Menu。
- 移动端使用 Logo + 菜单 + 预约咨询按钮，避免导航拥挤。

### 首屏 Hero

版式：
- 左文案，右主视觉。
- 底部横向四个指标。
- CTA 双按钮：预约方案咨询、查看客户案例。

指标建议：

```text
80% 大型国央企 / 政府监管客户
1000+ 重点建设项目
80+ 专利软著
100+ 国家级、省部级奖项
```

说明：
- “2014 年成立”不放首页首屏指标位，可放到关于筑云、发展历程或页脚。
- 首屏指标优先服务信任转化，客户结构和项目经验比成立年份更有说服力。

### 模块节奏

首页 8 个模块的视觉节奏建议：

1. 首屏：强转化，高信任。
2. 痛点：让客户对号入座。
3. 能力地图：把复杂业务讲成体系。
4. 产品：展示可购买、可落地的能力。
5. 方案：完成客户分流。
6. 技术：解释为什么筑云能做。
7. 案例：证明做过、做成过。
8. 背书 CTA：收口转化。
