## 首页文案使用注意

1. 首页避免放过长公司介绍，公司历史与区域布局放到“关于筑云”。
2. 首屏必须有真实产品界面、驾驶舱或项目视觉，不能只用抽象背景。
3. “1000+、80+、100+、80%”等数字上线前需由公司统一最终口径。
4. 案例卡片上线前建议补齐“客户、行业、产品服务、成果”四类字段。
5. 每个主要模块都应有进入二级页的入口，但不要让首页承担所有解释工作。
