## 2. 公司简介

### 模块标题

```text
筑云科技是谁
```

### 正文建议

```text
筑云科技是一家面向建设工程行业 AEC 场景的一体化数字建设解决方案服务商。公司以自主研发平台为基础，将 BIM、GIS、物联网、AI、数字孪生和工程数字技术与项目管理、现场监管、企业运营和数字化交付结合，帮助建设单位、施工企业、全咨监理、政府监管、院校和运营单位提升工程数字化能力。
```

```text
公司总部位于重庆，并在北京、深圳、杭州、成都等地设有服务网络，可为全国客户提供工程数字化产品、技术咨询和项目实施服务。
```
