## 1. 当前阶段结论

新版官网建议从“产品与服务展示型网站”升级为：

```text
面向建设单位、施工企业、全咨监理、政府监管、院校与运营单位的一体化数字建设解决方案官网。
```

核心表达主线：

```text
筑云是谁：
深耕建设工程行业的一体化数字建设解决方案服务商。

筑云有什么：
飞椽 Fyra 智能开发平台、BIMCC 智能建造平台、智慧工地、数字孪生、BIM 咨询、工程数字技术和数字化教育体系。

筑云解决什么：
企业级、项目级、行业级、监管级、运维级工程数字化问题。

为什么可信：
1000+ 重点项目、80% 大型国央企 / 政府监管客户、80+ 产品专利软著、100+ 国家级 / 省部级奖项和大量真实案例。
```

```text
“80% 大型国央企 / 政府监管客户”的展示表述
```

```text
顶部导航是否最终保留“资源中心”

产品平台是否需要 Mega Menu
解决方案是否需要按角色 / 行业 / 层级三列 Mega Menu
```


## 11. 下一阶段建议

### 阶段 A：管理层确认版

```text
1. 确认 Sitemap 与顶部导航
2. 确认首页 8 模块
3. 确认首页 Hero 核心数字
4. 确认 P0 / P1 页面优先级
5. 确认首页精选案例名单
```

### 阶段 B：视觉设计版

```text
1. 提供或确认视觉参考网站
2. 确认主视觉方向：平台驾驶舱型为主，工程现场型和研发底座型辅助
3. 准备 Logo、产品截图、案例图、证书图、二维码和真实项目素材
4. 输出首页桌面端视觉稿
5. 输出首页移动端视觉稿和组件规范
```

### 阶段 C：开发 / CMS 版

```text
1. 根据文案稿拆 CMS 字段
2. 建立产品、方案、案例、资源内容模型
3. 开发首页与核心二级页
4. 接入表单、下载、电话、二维码和 SEO 字段
5. 做移动端、性能、链接和内容验收
```

### 阶段 D：本地 HTML 原型版

```text
1. 新建 prototype/bimcc-home/
2. 生成首页 index.html、styles.css、script.js
3. 用首页 8 模块验证本地预览体验
4. 标注 placeholder、pending、待复核和待授权内容
5. 根据评审反馈进行快速修改
6. 进入高保真视觉前提醒提供视觉参考
```
