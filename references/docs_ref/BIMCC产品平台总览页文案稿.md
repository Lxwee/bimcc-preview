## 3. 核心产品卡片

### 3.1 飞椽 Fyra 智能开发平台

```text
工程行业 AI+零代码开发底座

飞椽 Fyra 将工程行业规则、业务模板、数据中台、物联网中台和 AI 能力融入零代码开发体系，支持页面、表单、流程、报表、大屏、工作台、APP/H5、设备组态等应用快速构建，帮助工程企业降低重复建设成本，提升数字化转型效率。

适用场景：企业级应用搭建、项目级平台快速交付、数字孪生系统构建、智慧工地应用扩展
按钮：了解飞椽 Fyra
```

### 3.2 BIMCC 智能建造平台

```text
项目全生命周期数字建造管理平台

BIMCC 智能建造平台以管理为核心、以 BIM 模型为载体、以物联网设备为触手，融合工程业务数据、模型数据和现场物联数据，覆盖协同办公、设计管控、质量安全、进度成本、物资设备、数字档案、BIMGIS 可视化和智慧运维等核心场景。

适用场景：建设单位项目监管、施工单位项目履约、企业多项目管控、政府/集团监管平台
按钮：查看 BIMCC 平台
```

### 3.3 智慧工地建设

```text
现场设备接入与项目智慧监管一体化

围绕项目现场安全、质量、进度、人员、设备、视频和环境监测等管理需求，筑云提供智慧工地建设全流程服务，支持现场物联网设备集成、数据采集、风险预警、视频联动和监管平台对接。

适用场景：房建、市政、轨道、高速、水利水电、机场等项目现场
按钮：查看智慧工地方案
```

### 3.4 数字孪生与智慧运维

```text
从建设交付到资产运营的一张图

通过数字孪生技术构建可视化运维驾驶舱，将空间模型、设备台账、监测数据、工单流程和档案资料进行融合，形成“实时监测、智能预警、协同处置、科学评估”的智慧运维管理模式。

适用场景：园区、公共建筑、轨道交通、文体场馆、综合体和基础设施运维
按钮：了解数字孪生运维
```

### 3.5 BIM 咨询服务

```text
全过程、全专业 BIM 技术服务

筑云为建筑工程、公路工程、市政工程等项目提供 BIM 实施顾问、设计协调、深化建模、施工应用、BIM+GIS 项目管理和数字化交付服务，覆盖机电、幕墙、钢结构、景观小市政、精装、装配式等专业方向。

适用场景：设计深化、施工模拟、进度管控、技术交底、竣工交付、平台数据融合
按钮：查看 BIM 咨询服务
```

### 3.6 工程 XR / 智慧展厅 / 指挥中心

```text
面向展示、汇报、培训和指挥的沉浸式工程体验

依托 BIMVR、AR/MR、3D 大屏、全息投影和数字孪生能力，筑云为企业、项目和高校打造智慧展厅、项目指挥中心、观摩会展示、虚拟仿真培训和工程 XR 应用。

适用场景：项目展示、迎检汇报、施工模拟、教育实训、企业展厅、指挥调度
按钮：查看工程 XR 服务
```

### 3.7 工程数字技术创新服务

```text
BIM+无人机、三维扫描、3DGS 等专项技术服务

筑云围绕工程现场数字化采集、逆向建模、进度比对、质量验评和实景融合，提供无人机全景进度管理、土石方测算、三维激光扫描、点云建模、3DGS+BIM 对比查看等创新技术服务。

适用场景：土石方测算、进度核验、实模一致验评、全景巡检、复杂空间扫描
按钮：了解创新技术服务
```

### 3.8 数字化教育体系

```text
面向高校与职教的智能建造教学与实训体系

筑云提供工程数字化课程资源、BIMVR/AR/MR 实训室、多维集成互动教学平台、数字化创新实训室和校企合作基地建设服务，帮助院校提升智能建造、BIM 和工程信息化人才培养能力。

适用场景：高校、职教院校、实训基地、BIM 课程建设、校企合作
```
