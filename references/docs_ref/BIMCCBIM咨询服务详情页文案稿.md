## 2. 典型痛点

### 模块标题

```text
BIM 的价值，不应停在建模和汇报
```

### 痛点列表

痛点 1：模型成果与现场管理脱节

```text
BIM 模型如果只用于展示和交付，无法持续服务进度、质量、安全、技术交底和施工协同。
```

痛点 2：设计协调与专业深化难落地

```text
机电、幕墙、钢结构、景观小市政、精装、装配式等专业之间交叉复杂，容易出现碰撞、返工和协同低效。
```

痛点 3：项目参与方缺少统一 BIM 管理机制

```text
业主、设计、施工、监理、咨询和分包对模型标准、交付深度、问题流程和资料归档理解不一致。
```

痛点 4：BIM 数据难进入平台

```text
模型、图纸、现场影像、无人机、三维扫描和工程资料如果没有平台承接，难以成为项目数据资产。
```

痛点 5：数字化交付要求越来越高

```text
竣工资料、模型成果、设备信息和过程档案需要面向后期运维和业主移交，而不是项目结束后临时整理。
```

## 5. 工程数字技术组合

### 模块标题

```text
BIM 咨询可以与现场数字采集能力一起交付
```

### 技术能力

BIM + 无人机：

```text
通过无人机拍摄施工现场和进度，结合工程全景监测平台，实现现场进度与 BIM 模型进度对比，并辅助现场管理。
```

无人机 + GIS 大场景建模：

```text
利用倾斜摄影等技术完成现场场地和工程逆向建模，支撑场地规划、全景进度和土方测算。
```

BIM + 三维扫描：

```text
通过三维激光扫描采集点云数据，与 BIM 模型对比，输出实测实量和偏差分析结果，提高质量检测效率。
```

3DGS + BIM 实景对比：

```text
支持不同时段实景场景对比、3DGS+BIM 分屏对比和实景问题标记，辅助进度核验和质量管理。
```

## 8. 实施路径

1. BIM 应用策划

```text
梳理项目类型、参建方、专业范围、交付要求、平台基础和 BIM 应用目标。
```

2. 标准与模型体系建立

```text
确定模型深度、命名规则、协同机制、审查流程、交付口径和平台数据要求。
```

3. 专业建模与深化

```text
开展机电、幕墙、钢结构、景观小市政、精装、装配式等专业建模、深化和协调。
```

4. 施工应用与平台融合

```text
将 BIM 成果接入项目管理、BIM+GIS、智慧工地、数字档案和现场应用场景。
```

5. 过程检查与成果沉淀

```text
持续输出问题报告、协调成果、应用资料、交底文件和阶段性 BIM 成果。
```

6. 数字化交付

```text
整理模型、图纸、资料、设备信息和平台数据，为竣工交付和智慧运维衔接提供基础。
```
