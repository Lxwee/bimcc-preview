## 4. 预约咨询表单

### 模块标题

```text
提交需求，获取方案建议
```

### 表单说明

```text
请简单说明你的组织角色、项目类型和当前需求。筑云团队会结合你的情况，匹配适合的产品组合、案例参考和实施路径。
```

### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 姓名 | 文本 | 必填 | 便于顾问联系 |
| 手机 / 电话 | 文本 | 必填 | 主要回访方式 |
| 公司 / 机构名称 | 文本 | 必填 | 判断客户类型和行业 |
| 职务 / 部门 | 文本 | 选填 | 如数字化、工程管理、项目部、采购等 |
| 所在地区 | 下拉 / 文本 | 选填 | 用于匹配区域服务团队 |
| 客户类型 | 下拉 | 必填 | 建设单位、施工单位、全咨 / 监理、政府监管、院校、运营单位、其他 |
| 需求类型 | 多选 | 必填 | 企业级平台、项目级平台、智慧工地、数字孪生、BIM 咨询、教育合作、其他 |
| 项目类型 | 多选 | 选填 | 房建、医院、文体教育、机场、科研办公、水利水电、轨道交通、市政道路、高速公路、其他 |
| 项目阶段 | 下拉 | 选填 | 前期、设计、施工、竣工、运维、企业规划阶段 |
| 当前系统基础 | 多选 | 选填 | 已有 OA / ERP / 项目管理系统 / 智慧工地 / BIM 模型 / 暂无系统 |
| 需求描述 | 长文本 | 必填 | 说明主要问题、目标或想了解的产品 |
| 资料上传 | 文件 | 选填 | 可上传需求说明、招标文件或项目资料，需做安全限制 |
| 隐私确认 | 勾选 | 必填 | 同意筑云科技按隐私政策联系并处理需求信息 |

## 7. 常见咨询问题

### 模块标题

```text
咨询前，你可能还想了解
```

### FAQ 建议

问题 1：筑云可以只做单个项目的平台吗？

```text
可以。筑云既支持项目级智能建造平台快速落地，也支持在试点项目基础上沉淀企业标准并逐步推广。
```

问题 2：已经有 OA、ERP 或项目管理系统，还能对接吗？

```text
可以根据已有系统、数据接口和管理边界进行集成设计，减少重复录入，并保护客户既有数字化投入。
```

问题 3：智慧工地设备可以接入统一平台吗？

```text
可以围绕实名制、视频监控、AI 识别、环境监测、车辆管理、应急广播等设备进行统一接入和监管。
```

问题 4：是否提供 BIM 咨询和数字化交付服务？

```text
可以。筑云服务覆盖 BIM 咨询、模型应用、施工深化、数字档案、数字化交付和智慧运维衔接等场景。
```

问题 5：官网提交需求后如何跟进？

```text
建议由市场或销售团队根据需求类型分配顾问，先进行需求沟通，再提供产品演示、方案建议或案例参考。
```
