## 1. 迁移原则

本次改版不是简单换视觉，也不是把宣传册逐页搬到网页上。内容迁移应遵循四个原则：

1. 首页只保留最能帮助访客判断和转化的内容。
2. 产品页讲清“平台能力、适用场景、模块、案例、交付方式”。
3. 解决方案页从客户角色和行业任务出发，不重复产品页。
4. 案例页结构化沉淀“客户、行业、问题、方案、成果”，作为销售和 SEO 资产复用。

---

## 2. 当前官网内容归并判断

当前官网已有顶部导航和页面骨架：

```text
首页 / 产品与服务 / 解决方案 / 客户案例 / 公司动态 / 荣誉资质 / 联系我们
```

新版建议升级为：

```text
首页 / 产品平台 / 解决方案 / 客户案例 / 技术与研发 / 资源中心 / 关于筑云 / 联系我们
```

主要变化：
- “产品与服务”更名为“产品平台”，强化飞椽 Fyra 与 BIMCC 智能建造平台的底座地位。
- “公司动态”并入“资源中心”，从新闻列表升级为产品动态、案例实践、行业洞察和资料下载。
- “荣誉资质”并入“关于筑云”下级，同时首页保留代表性信任背书。
- 新增“技术与研发”，承接多引擎、AI、IoT、零代码、专利软著和国产化适配。

## 10. 迁移验收标准

上线前检查：
- 首页不超过 8 个主模块。
- 顶部导航包含“首页”。
- 首页指标不使用“2014 年成立”作为首屏主背书。
- 产品页不只是功能罗列，必须包含适用客户、解决问题、典型案例和 CTA。
- 解决方案页不重复产品页，必须从客户角色或行业场景出发。
- 案例页必须结构化，不能只是项目图片墙。
- 宣传册 OCR 错字不得直接进入官网。
- 所有页面都有明确下一步 CTA。
