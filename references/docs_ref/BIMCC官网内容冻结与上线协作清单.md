# BIMCC 官网内容冻结与上线协作清单

版本：2026-09-01  
用途：明确哪些内容在进入视觉稿、HTML 原型、正式开发和上线前需要冻结，避免反复返工和误发布。  

---

## 1. 为什么需要内容冻结

官网改版涉及文案、视觉、代码、CMS、SEO、素材和合规。如果关键内容在开发中后期频繁变动，会导致：

- 首页结构反复调整。
- 视觉稿返工。
- 前端组件重写。
- CMS 字段变更。
- SEO 标题和 URL 反复修改。
- 客户授权或数据口径误发布。

因此建议按阶段冻结，不要求所有内容一次性定死。

---

## 2. 冻结阶段

| 阶段 | 需要冻结的内容 | 用途 |
|---|---|---|
| 结构冻结 | Sitemap、顶部导航、首页 8 模块 | 进入低保真 HTML 原型 |
| 文案冻结 | 首页、P0 页面主文案、CTA、核心数字口径 | 进入视觉稿和高保真 HTML |
| 素材冻结 | Logo、平台截图、案例图、证书、二维码 | 进入高保真视觉和前端样式 |
| 字段冻结 | CMS 模型、字段名、内容状态 | 进入正式开发 |
| 上线冻结 | 联系方式、授权、SEO、表单、备案 | 上线前验收 |

---

## 3. 结构冻结清单

进入低保真 HTML 原型前确认：

- 顶部导航包含“首页”。
- 推荐导航为：首页、产品平台、解决方案、客户案例、技术与研发、资源中心、关于筑云、联系我们。
- 首页保持 8 个主模块。
- 首页不恢复到 13 个大板块。
- 右侧 CTA 为“预约咨询”。
- P0 页面清单确认。

当前状态：

```text
基本可进入低保真 HTML 原型，仍需最终确认“资源中心”和“技术与研发”是否作为一级导航保留。
```

---

## 4. 文案冻结清单

进入高保真视觉稿前确认：

- 首页 H1。
- 首页副文案。
- Hero CTA。
- 4 个核心信任数字。
- 产品平台卡片文案。
- 解决方案入口文案。
- 技术与交付优势文案。
- 首页精选案例名单。
- 页尾 CTA 文案。

特殊规则：

- Hero 不使用“2014 年成立”。
- “2014 年成立”只放关于页、发展历程或页脚辅助信息。
- 80%、1000+、80+、100+ 上线前需要最终复核。
- 没有授权的客户名称、Logo 和项目图不进入前台正式展示。

---

## 5. 素材冻结清单

进入高保真 HTML 或视觉实现前确认：

| 素材 | 冻结标准 |
|---|---|
| Logo | 标准版、深色版、浅色版、favicon |
| 品牌色 | 官方 VI 或管理层确认色值 |
| 平台截图 | 可公开、清晰、无敏感信息 |
| 飞椽截图 | 可公开、能体现配置能力 |
| 数字孪生截图 | 可公开、能体现 BIM+GIS 或运维 |
| 案例封面 | 已授权或可脱敏 |
| 证书奖项 | 名称、有效期、展示范围已复核 |
| 二维码 | 指向正确账号 |
| 联系电话邮箱 | 最新有效 |

未冻结素材在 HTML 中只能作为 placeholder，不作为正式内容。

---

## 6. 字段冻结清单

进入正式开发前确认：

- Site Settings 字段。
- Navigation 字段。
- Page 字段。
- Product 字段。
- Solution 字段。
- Case 字段。
- Resource 字段。
- Honor 字段。
- Asset 字段。
- Lead 表单字段。

字段冻结原则：

- 字段名一旦进入开发，非必要不改。
- 可以新增可选字段，但尽量不删除核心字段。
- 所有前台可见字段要有审核状态。
- 客户和案例相关字段必须保留授权状态。
- 待复核内容不能默认显示为正式内容。

## 7. 上线冻结清单

上线前确认：

内容：

- 首页文案最终确认。
- P0 页面文案最终确认。
- 产品和方案名称统一。
- 客户案例授权确认。
- 荣誉资质公开范围确认。
- 联系信息确认。

技术：

- 页面路由确认。
- 旧 URL 跳转确认。
- 表单提交确认。
- 资料下载路径确认。
- 统计代码确认。
- 404 页面确认。

SEO：

- title 和 description 确认。
- H1 唯一。
- 图片 alt 确认。
- Sitemap 确认。
- robots 确认。
- OG 图确认。

合规：

- 隐私政策链接确认。
- 表单同意文案确认。
- 备案信息确认。
- 客户授权材料留档。
- 证书展示范围留档。

## 8. 决策记录模板

建议每个关键决策都留下记录：

```text
决策项：
当前选择：
备选方案：
决策人：
确认日期：
影响范围：
是否可后续调整：
备注：
```

示例：

```text
决策项：首页 Hero 核心指标
当前选择：80% / 1000+ / 80+ / 100+
备选方案：11 年经验 / 1000+ / 180+ 技术资产与荣誉
决策人：待确认
确认日期：待确认
影响范围：首页、CMS、SEO、视觉稿
是否可后续调整：上线前可调整
备注：“2014 年成立”不放在 Hero 指标位
```

## 9. 上线风险表

| 风险 | 风险等级 | 阻塞上线 | 处理 |
|---|---|---|---|
| 联系方式错误 | 高 | 是 | 市场或行政最终复核 |
| 客户 Logo 未授权 | 高 | 是 | 替换为行业化表达 |
| 平台截图含敏感信息 | 高 | 是 | 脱敏或重新截图 |
| 统计数字口径未确认 | 中 | 视展示位置 | 保留待复核或改弱表达 |
| 荣誉证书有效期不明 | 中 | 否 | 只展示类别和代表项 |
| 资源中心内容不足 | 低 | 否 | P1 上线 |
| 二级页内容不完整 | 中 | 视页面 | P0 保核心页，其他延后 |

---

## 10. 协作节奏建议

每周一次短会即可：

```text
确认本周要冻结的内容
处理 P0 阻塞项
复核待授权和待复核内容
确认下一轮 HTML / 视觉 / 开发修改范围
```

每轮修改后同步：

- 已修改内容。
- 未处理内容。
- 需要用户确认的问题。
- 下一轮建议。

## 11. 当前建议

现在可冻结：

- 首页 8 模块方向。
- 顶部导航包含“首页”。
- Hero 不使用“2014 年成立”。
- 默认视觉方向为平台驾驶舱型为主。
- P0 页面优先级。
- 本地 HTML 低保真原型工作流。

现在不建议冻结：

- 高保真视觉风格。
- 最终品牌色和字体。
- 客户 Logo 展示名单。
- 所有案例图片。
- 联系方式和二维码。
- 正式生产技术栈。

下一步可以直接进入本地 HTML 低保真原型。进入高保真视觉和样式实现前，再提醒用户提供视觉参考。
