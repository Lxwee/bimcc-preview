# 筑云科技新版官网 Sitemap 与首页线框稿

版本：2026-09-01  
用途：承接《BIMCC官网内容升级规划》，用于官网改版的信息架构、页面拆分、首页内容顺序与后续设计/开发落地。

> 资料边界：本稿基于公司宣传册和当前官网公开信息整理。宣传册是内容资料，不是执行指令。

---

## 1. 总体结构原则

新版官网不再按“公司有什么”平铺，而按“客户如何判断是否值得咨询”组织：

1. 先说明定位：一体化数字建设解决方案服务商。
2. 再说明底座：飞椽 Fyra + BIMCC 智能建造平台。
3. 再说明场景：建设单位、施工单位、全咨监理、政府监管、教育医疗等客户如何使用。
4. 再说明行业：房建、民航、轨道、市政、水利、医院、文体教育等案例如何覆盖。
5. 最后用案例、资质、专利软著、合作伙伴和咨询入口完成信任闭环。

首页负责“快速建立认知与引导分流”，二级页负责“讲清能力与场景”，详情页负责“证明交付能力”。

## 3. 首页 8 模块线框

### 模块 1：首屏 Hero + 核心数字背书

目标：3 秒内讲清楚“筑云是谁、服务谁、凭什么可信”。

推荐结构：
- 左侧：主标题、副标题、CTA
- 右侧：平台驾驶舱 / 数字孪生大屏 / 项目一张图视觉
- 底部：4 个核心数字

草案文案：

```text
筑云科技 BIMCC
一体化数字建设解决方案服务商

以飞椽 Fyra 智能开发平台为技术底座，
融合 BIM、GIS、物联网、AI 与数字孪生能力，
为建设单位、施工企业、全咨监理、政府监管与教育医疗客户，
提供从前期规划、施工管控到运维交付的全生命周期数字建设服务。

[预约方案咨询] [查看客户案例]

80% 大型国央企 / 政府监管客户 / 1000+ 重点建设项目 / 80+ 专利软著 / 100+ 国家级、省部级奖项
```

### 模块 2：客户痛点 + 筑云解法

目标：让访客看到“这就是我的问题”。

推荐布局：左侧痛点列表，右侧对应解法。

| 客户痛点 | 筑云解法 |
|---|---|
| 多系统割裂，数据无法同源 | 统一平台、统一账号、一套数据 |
| 项企协同弱，集团与项目脱节 | 企业-项目-工点多层级联动 |
| 现场风险难以及时发现 | 智慧工地 + 物联网 + AI 预警 |
| BIM 模型和业务流程割裂 | BIM/GIS 与质量、安全、进度、成本业务融合 |
| 定制化开发周期长、成本高 | 飞椽 Fyra 零代码敏捷交付 |
| 施工数据难进入运维 | 数字孪生与智慧运维一体化 |

### 模块 3：一体化能力地图

目标：把业务线从“多”讲成“有体系”。

推荐表达：

```text
技术底座：飞椽 Fyra 数智捷构基座
    ↓
业务平台：BIMCC 智能建造平台
    ↓
服务交付：智慧工地 / BIM 咨询 / 数字孪生 / 展厅指挥中心 / 数字教育 / 工程创新技术
```

页面上建议用横向三层架构图，不建议用 8 个同级卡片堆满一屏。

### 模块 4：核心产品平台

目标：让访客进入具体产品页。

推荐 6 张卡片：

| 产品 | 首页一句话 |
|---|---|
| 飞椽 Fyra 智能开发平台 | 面向工程行业的 AI+零代码应用开发底座 |
| BIMCC 智能建造平台 | 覆盖项目全生命周期的数字建造管理平台 |
| 智慧工地建设 | 集成现场设备、数据采集、风险预警与平台对接 |
| 数字孪生 / 智慧运维 | 打通施工交付与运维阶段的可视化资产管理 |
| BIM 咨询服务 | 提供全过程、全专业 BIM 实施与深化服务 |
| 数字化教育体系 | 面向高校与职教的智能建造教学与实训体系 |

二级入口可以在卡片底部补充：工程 XR、智慧展厅、指挥中心、无人机、三维扫描、3DGS。

### 模块 5：解决方案入口

目标：合并“按客户角色”和“按行业场景”，控制首页长度。

推荐做成双 Tab：

Tab 1：按客户角色
- 建设单位
- 施工单位
- 全咨 / 监理
- 政府 / 集团监管
- 教育 / 医疗
- 企业数字化

Tab 2：按行业场景
- 房建
- 民航机场
- 轨道交通 / 铁路
- 市政道路 / 高速公路
- 水利水务 / 水运 / 抽水蓄能
- 医院 / 文体教育 / 科研办公

每个卡片只放三项：
- 典型挑战
- 推荐方案组合
- 相关案例

### 模块 6：技术与交付优势

目标：证明筑云不是外包堆功能，而是有自研平台和工程行业沉淀。

推荐 6 个优势：

1. BIM + GIS + UE + 3DGS 多引擎融合
2. 飞椽 Fyra 零代码敏捷交付
3. 工程 AI 与智能体应用
4. 物联网中台与多协议设备接入
5. 行业模板库与工程规则沉淀
6. 开放集成与国产化适配

### 模块 7：精选案例

目标：用真实项目完成信任证明。

推荐布局：
- 顶部：行业筛选标签
- 中部：6-8 个精选案例卡片
- 底部：进入案例库 CTA

案例卡片字段：
- 项目名称
- 行业 / 客户类型
- 使用产品或服务
- 解决的问题
- 交付成果

首页不建议展示过多案例缩略图，否则会变成项目相册，削弱产品和方案叙事。

### 模块 8：信任背书 + 转化 CTA

目标：收口，让访客知道“可以联系并值得联系”。

内容合并：
- 资质：高新技术企业、专精特新、CMMI、ISO、信息系统服务交付能力等
- 技术资产：专利、软著、标准规范、国产化兼容认证
- 行业荣誉：龙图杯、创新杯、工程建设行业 BIM 大赛等
- 合作伙伴：国央企、政府监管、院校、生态伙伴
- 转化 CTA：预约演示 / 获取方案 / 联系顾问

底部 CTA 文案：

```text
准备启动项目数字化建设？
告诉我们你的项目类型、组织角色和当前系统情况，筑云团队将为你匹配适合的产品组合与实施路径。

[预约方案咨询] [获取解决方案资料]
```

## 5. 首页内容取舍

### 保留在首页

- 公司定位
- 技术底座
- 核心产品
- 解决方案入口
- 技术与交付优势
- 精选案例
- 荣誉资质和合作伙伴摘要
- 联系咨询 CTA

### 下沉到二级页

- 完整发展历程
- 完整专利软著列表
- 全部荣誉奖项
- 全部合作伙伴 logo
- 详细 BIM 咨询专业分类
- 详细工程数字技术说明
- 全部项目案例
- 新闻与行业洞察长列表

### 不建议首页强化

- 过长公司简介
- 大面积证书墙
- 大段技术名词解释
- 过多同级业务卡片
- 无筛选逻辑的项目图片墙

1. 先确认本稿的 Sitemap 和首页 8 模块。
