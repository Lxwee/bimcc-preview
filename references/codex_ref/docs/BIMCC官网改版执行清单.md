## 6. 阶段 5：内容迁移

### 迁移原则

- 官网现有内容：能保留的保留，能合并的合并，重复和弱内容下线。
- 宣传册内容：不整页照搬，拆成首页卖点、产品页能力、方案页场景、案例页证据。
- 案例内容：优先结构化，便于筛选、复用和 SEO。

### 页面迁移方式

| 内容类型 | 处理方式 |
|---|---|
| 公司介绍 | 精简后放关于页和 Footer |
| 产品介绍 | 拆成产品总览页 + 重点产品页 |
| 解决方案 | 按客户角色和行业场景重写 |
| 案例业绩 | 结构化进入案例库 |
| 荣誉资质 | 代表性首页露出，完整内容进入详情页 |
| 新闻动态 | 改造成资源中心 |
| 合作伙伴 | 分组展示，不做无序 Logo 墙 |

## 7. 阶段 6：上线验收

### 内容验收

- 首页 8 模块顺序完整。
- 顶部导航包含“首页”。
- 所有 CTA 指向有效联系方式或表单。
- 首页核心数字口径统一。
- 产品、方案、案例之间有相互跳转。
- 没有宣传册 OCR 错字直接进入官网。

### 设计验收

- 桌面端首屏能在 3 秒内传达公司定位。
- 移动端首屏不被主视觉挤压。
- 首页不超过 8 个主模块。
- 产品卡片、方案卡片、案例卡片样式统一。
- 证书和 Logo 不喧宾夺主。

### 技术验收

- 移动端、平板、桌面端响应式正常。
- 表单提交、电话、二维码、下载链接可用。
- 页面标题、描述、H1-H3 层级合理。
- 图片压缩和懒加载处理完成。
- 无明显布局溢出、错位、文本遮挡。
- 关键页面加载速度满足上线要求。

### SEO 验收

- 首页标题包含“筑云科技 BIMCC”和“一体化数字建设解决方案”。
- 产品页覆盖“智能建造平台、BIM 智慧工地、数字孪生、BIM 咨询”等关键词。
- 解决方案页覆盖建设单位、施工单位、企业级、项目级、全咨监理、民航、轨道、市政、水利等关键词。
- 案例详情页有项目名、行业、产品服务、交付成果。
- 图片 alt 文案使用真实内容，不堆关键词。
