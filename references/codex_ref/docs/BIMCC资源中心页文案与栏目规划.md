## 2. 页面结构

### 推荐模块顺序


## 3. 内容栏目

```text

```

```text

```

示例主题：


### 栏目 3：案例实践


示例主题：

## 6. 文章详情模板

### 推荐结构

```text
1. 标题与摘要
2. 文章标签
3. 正文内容
4. 关键观点 / 摘要
5. 相关产品或方案
6. 相关案例
7. 资料下载或咨询 CTA
```

### 详情页原则

```text
每篇文章至少关联一个产品页或解决方案页。案例实践类文章应关联案例详情页，资料下载类文章应进入表单或下载流程。
```

## 7. 资料下载机制

### 下载方式建议

```text
公开资料：可直接下载，如通用产品介绍、公开宣传册。
留资资料：填写姓名、电话、公司、需求类型后下载，如解决方案 PDF、行业白皮书、案例集。
申请资料：提交用途后由销售或市场人员跟进，如资质证明、投标材料、详细报价资料。
```

### 表单字段

```text
姓名
联系电话
公司 / 机构
职务 / 部门
资料类型
需求描述
隐私确认
```

## 8. SEO 与内容运营规则

### 标题规则

```text
文章标题应包含真实主题、行业或产品关键词，避免“重磅发布”“喜讯”等只有内部视角的标题。
```

### 内容规则

```text
行业洞察要讲观点和方法，不写空泛趋势。
产品动态要讲场景和使用价值，不只写版本发布。
案例实践要讲客户问题、方案能力和交付成果，不只写项目名称。
公司新闻要连接品牌可信度，不占用过多官网主转化空间。
```

### 关联规则

```text
每篇内容至少关联：1 个产品 / 服务、1 个解决方案或案例、1 个 CTA。
```
