# 客户案例详情页模板文案稿

版本：2026-09-01  
适用页面：客户案例 / 案例详情  
页面目标：统一案例详情页结构，把项目背景、客户问题、筑云方案、平台能力、交付成果和相关跳转组织成可复用模板，便于后续批量录入 CMS。

---

## 1. 页面定位

### 页面标题格式

```text
{案例名称}｜客户案例
```

### 首屏主标题格式

```text
{案例名称}
```

### 首屏副标题格式

```text
筑云科技围绕 {行业场景} 的 {客户角色 / 项目管理目标}，提供 {核心产品 / 服务组合}，支撑项目在 {核心业务场景} 上实现数字化管理与协同。
```

### 首屏信息标签

```text
行业：{行业场景}
客户类型：{建设单位 / 施工单位 / 集团 / 院校 / 运营单位}

关联方案：{解决方案名称}
```

### 首屏 CTA

```text
获取同类项目方案
查看相关解决方案
```

### 首屏视觉

```text
建议使用项目实景图、平台驾驶舱截图或 BIM+GIS 一张图作为主视觉；如截图未获授权，可使用行业化项目照片 + 平台模块局部图。
```

## 2. 页面结构

### 推荐模块顺序

```text
1. 首屏 Hero + 案例标签
2. 项目背景
3. 客户挑战
4. 筑云方案
5. 核心建设内容
6. 平台能力展示
7. 交付成果
8. 相关产品与解决方案
9. 相似案例
10. 底部 CTA
```

### 内容原则

```text
案例详情页要避免只写“项目名称 + 平台名称”。每页至少回答：客户为什么需要做、筑云做了什么、交付了哪些能力、能证明什么。
```

### 方案说明模板


### 推荐表达结构

```text

展示决策：说明驾驶舱、一张图、大屏、报表和预警能力。
交付运营：说明培训、试运行、持续迭代和运维机制。
```

## 14. 素材需求

P0：
- 案例封面图
- 项目实景图或平台截图
- 客户名称 / Logo / 项目名称公开授权状态
- 行业、客户类型、产品服务和项目层级字段
- 3-5 条核心建设内容

P1：
- 项目背景补充资料
- 客户挑战与实施过程说明
- 可公开量化成果
- 奖项、验收、媒体报道或客户评价
- 平台多端截图：PC、移动端、大屏
