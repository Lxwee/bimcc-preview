## 4. 多引擎融合能力

### 模块标题

```text
BIM、GIS、UE、3DGS 不是展示素材，而是业务数据的空间载体
```

### 能力说明

BIM：

```text
承载构件、专业模型、施工深化、质量验评、设备台账和数字化交付信息。
```

GIS：

```text
承载区域、线路、标段、工点、项目分布和多项目空间监管关系。
```

UE：

```text
支撑更高表现力的三维场景、汇报展示、仿真演示和指挥中心应用。
```

3DGS：

```text
结合实景扫描和现场影像，实现实景模型、时序对比、实模一致和空间问题标记。
```

业务数据：

```text
将进度、质量、安全、成本、设备、资料、工单、风险和预警数据挂接到空间载体中，形成可管理的一张图。
```

## 5. 工程 AI 与智能化能力

### 模块标题

```text
AI 能力要进入工程业务流程，而不是停留在概念层
```

### 应用方向

```text
AI 智能识别：结合现场视频、图像和设备数据，辅助识别安全风险和现场异常。
工程知识助手：围绕项目资料、标准规范、企业知识库和平台数据，辅助检索和问答。
风险研判：结合质量安全、进度履约、设备报警和项目台账，辅助风险提示和处置建议。
智能应用构建：通过飞椽 Fyra 支撑工程 AI 应用、表单、流程、看板和专题工具快速构建。
```

### 表达边界

```text
官网不建议泛泛使用“AI 赋能一切”。应把 AI 放到具体场景中表达，如 AI 安全识别、AI 标书编制、AI 工作助手、工程知识库和风险预警。
```
