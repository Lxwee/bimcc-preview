# BIMCC 官网首页 HTML 原型实现说明

版本：2026-09-01  
用途：把首页文案、wireframe 和模块级版式说明转化为本地 HTML 原型的实现蓝图。  

---

## 1. 原型目标

本地 HTML 原型用于验证：

- 首页 8 个主模块的阅读顺序。
- 顶部导航和 CTA 是否清楚。
- 首屏定位是否能快速传达。
- 产品平台、解决方案、案例和信任背书之间是否连贯。
- 移动端是否能保持清晰浏览。

该原型不是最终官网代码，不接 CMS，不提交真实表单。

---

## 2. 页面骨架

建议首页 HTML 骨架：

```html
<header class="site-header"></header>
<main>
  <section class="hero"></section>
  <section class="pain-solution"></section>
  <section class="capability-map"></section>
  <section class="product-platforms"></section>
  <section class="solution-entry"></section>
  <section class="delivery-advantages"></section>
  <section class="featured-cases"></section>
  <section class="trust-cta"></section>
</main>
<footer class="site-footer"></footer>
```

注意：

- 首页保持 8 个主模块。
- 信任数字并入 Hero 或紧随 Hero，不新增成第 9 个大板块。
- 页脚不计入首页主模块。

## 3. Header 实现

内容：

```text
Logo：筑云科技 BIMCC
导航：首页 / 产品平台 / 解决方案 / 客户案例 / 技术与研发 / 资源中心 / 关于筑云 / 联系我们
```

实现要求：

- 桌面端导航一行显示，高度不超过 80px。
- “首页”必须在导航中。
- CTA 只有一个主要意图，统一为“预约咨询”。
- 移动端折叠菜单中保留完整导航。
- 导航链接先用锚点或本地占位链接，后续再替换为正式 URL。

HTML 建议：

```html
<nav class="primary-nav" aria-label="主导航">
  <a href="#home">首页</a>
  <a href="#products">产品平台</a>
```

## 10. 模块 7：精选案例

首页展示 6 个以内精选案例，更多进入案例库。

卡片字段：

```text
案例标题
客户类型
行业场景
使用产品 / 服务
成果摘要
授权状态
```

授权规则：

- 客户名称待授权时，前台使用行业化表达。
- 客户 Logo 待授权时，不展示 Logo。
- 项目图片待授权时，使用可公开项目图或占位图。
- 成果数据待复核时，不写成确定成果。

## 13. 可访问性与 SEO

HTML 语义：

- 页面只有一个 H1。
- 每个大模块用 H2。
- 卡片标题用 H3。
- 导航使用 `nav` 和 `aria-label`。
- 表单字段使用 `label`，不把 placeholder 当标签。

图片 alt 应描述真实内容：

```text
BIMCC 智能建造平台项目驾驶舱界面
飞椽 Fyra 流程配置界面
智慧工地现场设备接入场景
```

占位图 alt：

```text
待替换的 BIMCC 平台截图占位
```

首页 title 建议：

```text
筑云科技 BIMCC - 一体化数字建设解决方案服务商
```

首页 description 建议：

```text
筑云科技 BIMCC 面向建设单位、施工企业、监管单位和运营单位，提供智能建造平台、智慧工地、数字孪生、BIM 咨询和工程数字技术服务。
```

## 14. 响应式实现

桌面端：

- 导航一行显示。
- Hero 左文案右主视觉。
- 核心数字可横向排列。
- 产品和方案模块使用不重复布局。
- 案例卡片控制在 2-3 列。

平板端：

- Hero 可上下或 6:6 分栏。
- 产品卡片 2 列。
- 方案入口 2 列。
- 案例卡片 2 列。

移动端：

- 导航折叠。
- Hero 文案优先，主视觉后置。
- 核心数字 2 列或单列。
- 所有卡片避免横向滚动。
- CTA 在首屏和页尾都容易点击。

## 15. 验收清单

低保真原型完成后检查：

- `index.html` 可直接打开。
- 首页 8 个模块顺序完整。
- 顶部导航包含“首页”。
- Hero 不展示“2014 年成立”。
- Hero 展示 80%、1000+、80+、100+ 四类信任信息。
- 待复核和待授权内容没有被写成已确认。
- 图片占位说明清楚。
- 移动端无横向溢出。
- CTA 指向本地锚点或占位链接。
- 表单不提交真实数据。

进入高保真样式前，需要用户提供视觉参考和真实素材。
