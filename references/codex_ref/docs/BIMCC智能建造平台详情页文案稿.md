## 2. 核心定位

### 模块标题

```text
把模型、现场、业务和数据统一到一个平台
```

### 模块说明

```text
工程项目管理不仅需要模型可视化，更需要进度、质量、安全、成本、物资设备、资料档案和多方协同的业务闭环。BIMCC 智能建造平台围绕项目全生命周期，将 BIM/GIS 可视化能力、现场物联网数据和项目管理流程融合在统一平台中，帮助客户实现看得见、管得住、可追溯、可沉淀的数字建造管理。
```

### 平台价值

价值 1：一张图看项目

```text
融合 BIM、GIS、实景、设备和业务数据，实现从宏观态势到微观工点的穿透式管理。
```

价值 2：一套平台管业务

```text
覆盖进度、质量、安全、成本、物资设备、协同办公、数字档案和运维等核心管理场景。
```

价值 3：多方协同同源数据

```text
支持业主、施工、监理、咨询、分包、BIM 咨询等多角色基于同源数据协同管理，并通过权限隔离保障边界清晰。
```

价值 4：项企联动沉淀资产

```text
打通企业、项目和工点之间的数据壁垒，让项目经验、业务模板和数据资产持续沉淀到企业管理体系。
```

价值 5：可快速适配不同项目

```text
依托飞椽云敏捷交付模式、应用模板库和定制化能力，适配不同业态、不同项目阶段和不同数字化成熟度。
```

## 8. BIM+GIS+UE+3DGS 多引擎融合

### 模块标题

```text
从模型可视化，到数字孪生工地
```

### 能力说明

```text
平台依托 BIM、GIS、UE、3DGS 多引擎融合技术，同时整合二维地图数据、三维模型数据、实景数据和业务数据，实现建设环境与模型的深度一体化，让虚拟模型与实体工地环境精准映射、实时联动。
```

### 引擎能力

| 引擎 | 能力 |
|---|---|
| BIM 引擎 | 模型轻量化、属性查询、场景关联 |
| GIS 引擎 | 二维地图整合、空间分析、宏观总览 |
| UE 引擎 | 可视化渲染、场景轻量化、沉浸式展示 |
| 3DGS 引擎 | 三维地理空间建模、多源数据适配、实景融合 |

### 业务支撑

```text
勘察设计、前期管理、质量管控、安全管控、进度管控、物资设备、计量管控、协同办公、数字化档案和运维管理。
```

### 重要表达

```text
业务功能不依赖 BIM 模型，可脱离 BIM 独立运行，适配不同项目的技术应用场景。
```
