# 客户案例列表页文案与字段规划

版本：2026-09-01  
适用页面：客户案例 / 案例库  
页面目标：把宣传册中的大量案例从“项目名罗列”升级为可筛选、可检索、可复用的案例库，帮助访客按行业、客户角色、产品服务和项目层级快速找到可信证明。

## 2. 页面结构

### 推荐模块顺序

```text
1. 首屏 Hero + 核心案例数据
2. 精选案例区
3. 案例筛选器
4. 案例列表 / 卡片网格
5. 行业覆盖说明
6. 产品服务关联入口
7. 底部咨询 CTA
```

### 设计原则

```text
案例列表页不建议做成密集 Logo 墙。每个案例卡片至少要呈现行业、客户类型、应用产品和一句话成果，让访客知道“为什么这个案例值得看”。
```

## 5. 筛选器设计

| 维度 | 推荐选项 |

| 行业场景 | 房建、医院、文体教育、民航机场、科研办公、水利水电、轨道交通、市政道路、高速公路、海外 |

## 8. 产品与方案关联

### 关联规则

```text
每个案例详情页至少关联 1 个产品页、1 个解决方案页和 1 个相似案例，形成“案例证明 - 方案承接 - 咨询转化”的闭环。
```

### 推荐跳转

| 案例类型 | 关联产品 | 关联方案 |
|---|---|---|
| 企业级平台 | 飞椽 Fyra / BIMCC 智能建造平台 | 企业级数字化运营与转型方案 |
| 项目级智能建造 | BIMCC 智能建造平台 / 智慧工地 | 项目级智能建造平台解决方案 |
| 建设单位项目 | BIMCC 智能建造平台 / 数字孪生 | 建设单位数字建管解决方案 |
| 施工单位项目 | BIMCC 智能建造平台 / 智慧工地 | 施工单位智能建造解决方案 |
| 运维类项目 | 数字孪生 / 智慧运维 | 数字孪生与智慧运维方案 |
| 教育类项目 | 数字化教育体系 / BIMVR | 教育 / 医疗基建数字化方案 |

## 9. 空状态与未授权处理

### 无结果文案

```text
暂未找到匹配案例。你可以调整筛选条件，或联系我们获取相近项目的解决方案建议。
```

### 未授权客户名称处理

```text
如客户名称、Logo 或平台截图暂未获得公开授权，可在案例卡片中使用“某大型交通基础设施项目”“某国有建设集团企业级监管平台”等行业化表达，但内部 CMS 仍保留真实项目名称用于管理。
```

## 11. 素材需求

P0：
- 首页精选 6-8 个案例封面图
- 每个精选案例的客户名称与 Logo 授权状态
- 每个精选案例的平台截图或项目实景图
- 案例行业、客户类型、产品服务和项目层级字段

P1：
- 案例详情页图库
- 奖项、验收、媒体报道或客户反馈材料
- 项目建设周期、规模、上线时间、使用角色等补充字段
- 可量化成果数据，如效率提升、问题闭环数量、资料归档量等
