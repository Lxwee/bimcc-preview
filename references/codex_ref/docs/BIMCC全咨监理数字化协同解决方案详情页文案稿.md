## 2. 典型痛点

### 模块标题

```text
全咨与监理的核心价值，需要被过程数据证明
```

### 痛点列表

痛点 1：参建方多，协同边界复杂

```text
业主、施工、设计、咨询、监理、分包和 BIM 服务团队同时参与项目，沟通链路长，责任边界容易模糊。
```

痛点 2：问题闭环依赖线下跟进

```text
质量、安全、进度和现场问题从发现到整改、复核、归档常分散在群消息、纸质单据和多个台账中。
```

痛点 3：过程资料难以持续归集

```text
监理日志、旁站记录、验收资料、会议纪要、影像资料和模型成果没有持续沉淀，后期汇报和交付压力大。
```

痛点 4：咨询成果难与项目数据联动

```text
BIM 咨询、设计协调、施工深化和专项分析成果若停留在文件交付层，难以进入项目日常管理闭环。
```

痛点 5：管理成效难量化

```text
咨询和监理团队做了大量过程工作，但缺少统一看板和数据口径，难以清晰证明管理价值和风险控制成效。
```

## 5. 核心应用场景

### 场景 1：多方协同与权限隔离

```text
通过统一平台支撑业主、施工、监理、咨询、设计和分包协同，同时按组织角色设置数据权限和业务边界。
```

### 场景 2：质量安全问题闭环

```text
覆盖问题发现、派发整改、现场反馈、复核验收和归档统计，形成质量安全问题的可追溯证据链。
```

### 场景 3：监理过程数字化

```text
支撑监理日志、旁站记录、巡检检查、会议纪要、监理报告和现场影像等资料在线流转与归集。
```

### 场景 4：BIM 咨询成果协同应用

```text
将 BIM 模型、设计协调、施工深化、碰撞检查和方案推演成果与项目管理流程结合，提升咨询成果使用效率。
```

### 场景 5：验收证据与数字档案

```text
围绕试验检测、质量检验、施工记录、中间交工、竣工资料和模型成果，持续沉淀可交付的数字档案。
```

### 场景 6：项目管理汇报与看板

```text
通过项目驾驶舱展示进度、质量、安全、问题闭环、资料归集和风险事项，支撑业主汇报与项目例会。
```

```text
接入 BIM 模型、图纸文件、现场影像、智慧工地数据、项目台账和既有资料。
```

5. 试运行与协同培训

```text
围绕典型业务流程开展试运行，培训业主、施工、监理和咨询等参建方角色。
```
