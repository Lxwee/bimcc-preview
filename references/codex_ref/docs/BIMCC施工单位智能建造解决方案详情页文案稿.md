## 2. 典型痛点

### 模块标题

```text
施工单位最难的，是把现场真实状态及时变成管理动作
```

### 痛点列表

痛点 1：项目多，标准难统一

```text
不同项目的管理流程、表单、台账和汇报方式差异大，企业难以形成统一标准和可复用模板。
```

痛点 2：质量安全闭环慢

```text
隐患发现、整改、复核、归档分散在不同工具和人员手中，过程留痕不足，管理责任难追溯。
```

痛点 3：进度与现场脱节

```text
计划进度、形象进度、现场影像、BIM 模型和施工任务之间缺少联动，项目履约风险难以及时判断。
```

痛点 4：成本、物资设备与生产割裂

```text
物资设备、合同支付、计量、成本和现场生产数据难以统一，影响项目精细化管理。
```

痛点 5：智慧工地设备多，平台分散

```text
实名制、视频、AI 识别、环境监测、车辆管理、洞内监测等设备系统分散，难以统一接入和分析。
```

## 5. 核心应用场景

### 场景 1：企业多项目履约监管

```text
为集团、工程局和分公司建立多项目看板，统一查看项目进度、安全质量、履约状态和风险预警。
```

### 场景 2：质量安全闭环管理

```text
覆盖安全巡检、质量检查、隐患整改、复核验收、危大工程、风险预警和过程归档，形成闭环台账。
```

### 场景 3：生产进度管理

```text
将进度计划、施工任务、形象进度、BIM 模型、现场影像和项目汇报进行联动，辅助项目团队及时掌握履约偏差。
```

### 场景 4：物资设备与成本商务协同

```text
围绕物资设备台账、进出场、使用状态、合同、计量支付和成本数据，提升项目精细化管控能力。
```

### 场景 5：智慧工地设备统一接入

```text
接入实名制、安全教育、人车定位、视频监控、AI 识别、环境监测、车辆管理、应急广播和隧洞监测等设备数据。
```

### 场景 6：观摩迎检与创优支撑

```text
结合智能建造平台、智慧工地、BIM 技术服务、智慧展厅和观摩会服务，支撑项目迎检、汇报、创优和品牌展示。
```


统一管理：


统一平台：

定制化：



## 8. 实施路径

1. 项目管理诊断

```text
梳理施工企业管理标准、项目类型、组织层级、现场设备、既有系统和重点管理目标。
```

2. 模块组合设计

```text
确定进度、质量、安全、成本、物资设备、智慧工地和数字档案等模块边界。
```

3. 平台配置与集成

```text
基于 BIMCC 平台和飞椽 Fyra 配置业务流程、表单、权限、报表、大屏和移动端入口。
```

4. 现场设备接入

```text
接入实名制、视频监控、AI 识别、环境监测、车辆管理、应急广播和其他智慧工地设备。
```

5. 试点项目运行

```text
在重点项目上验证流程闭环、设备数据、项目驾驶舱和管理成效。
```

6. 企业级复制推广

```text
沉淀项目模板、业务标准、案例经验和管理指标，支撑更多项目快速复用。
```
