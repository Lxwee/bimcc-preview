## 2. 页面结构

### 推荐模块顺序

```text
1. 首屏 Hero + 核心资质数字
2. 企业资质 / 认证
3. 国产化与生态适配
4. 专利软著
5. 标准编制
6. 行业奖项
7. 资质查询与下载说明
8. 底部 CTA
```

### 展示原则

```text
荣誉资质页要强调分类和可信度，不做密集图片墙。证书名称、颁发机构、有效期和展示状态应进入 CMS 字段，便于后续维护。
```
