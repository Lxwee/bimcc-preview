# BIMCC 官网素材采集与命名规范

版本：2026-09-01  
用途：统一新版官网所需图片、截图、Logo、证书、PDF、二维码和视频素材的采集、命名、授权、裁切和交付规则。  
适用范围：首页视觉稿、产品页、解决方案页、案例库、荣誉资质页、资源中心、联系我们页和后续前端开发。

资料边界：宣传册和官网信息仅作为素材线索。所有素材需确认来源、公开授权、使用范围和是否可出现在官网。

---

## 1. 素材原则

### 真实优先

新版官网的信任感来自真实内容：
- 真实产品界面截图。
- 真实项目现场图。
- 真实 BIM+GIS、数字孪生或平台驾驶舱画面。
- 真实证书、奖项和合作资质。
- 真实客户案例与可公开成果。

### 不建议使用

- 抽象科技光效替代平台能力。
- 无授权客户 Logo。
- 无法证明来源的证书或奖项截图。
- 纯 AI 生成的工程项目图冒充真实案例。
- 模糊、过暗、过度裁切、文字无法辨认的平台截图。
- 带测试数据、客户敏感信息、账号信息的后台截图。

### 可使用占位

当素材暂未到位时，可以使用明确占位：

```text
TODO: 待提供 BIMCC 智能建造平台首页截图，建议 2400x1350，需脱敏。
```

占位不得伪装成真实案例或真实客户截图。

## 3. 文件命名规则

### 基础规则

使用英文小写和短横线，避免中文文件名进入前端代码和 CMS URL。

```text
{type}-{subject}-{variant}-{size}.{ext}
```

字段说明：
- `type`：hero、product、case、honor、partner、resource、contact 等。
- `subject`：平台、产品、案例或页面主题。
- `variant`：desktop、mobile、cover、detail、logo、dark、light 等。
- `size`：可选，如 2400x1350、1200x630。

### 命名示例

```text
hero-platform-dashboard-2400x1350.jpg
fyra-devstudio-editor-1920x1200.jpg
bimcc-project-map-1920x1080.jpg
smart-site-device-1600x1200.jpg
digital-twin-operation-1920x1080.jpg
case-hainan-jiaotou-cover-1600x1200.jpg
case-chongqing-rail-15-cover-1600x1200.jpg
honor-cmmi-certificate-1200x1600.jpg
partner-logo-xxx-light.svg
contact-qrcode-wechat-800x800.png
resource-smart-construction-cover-1200x675.jpg
og-home-bimcc-1200x630.jpg
```

### 禁止命名

```text
图片1.png
首页最终版2.jpg
新官网素材-不要删.png
客户logo最新版最终确认版.svg
微信图片_20260901120000.jpg
```

## 5. 尺寸与比例规范

| 场景 | 建议比例 | 建议尺寸 | 格式 | 说明 |
|---|---|---:|---|---|
| 首页 Hero 主视觉 | 16:9 或 16:10 | 2400x1350 / 2400x1500 | jpg/png/webp | 平台驾驶舱或 BIM+GIS |
| 产品截图 | 16:10 | 1920x1200 | png/webp | 文字需清晰，需脱敏 |
| 案例封面 | 4:3 或 16:9 | 1600x1200 / 1600x900 | jpg/webp | 项目现场或平台应用 |
| 资源封面 | 16:9 | 1200x675 | jpg/webp | 列表和分享 |
| OG 分享图 | 1.91:1 | 1200x630 | jpg/png | 每类页面至少 1 张 |
| 证书图片 | 3:4 或原比例 | 1200x1600 以上 | jpg/png | 保证名称可读 |
| Logo | 原比例 | svg 优先 | svg/png | 提供深浅两版 |
| 二维码 | 1:1 | 800x800 以上 | png | 不压缩变形 |
| 视频封面 | 16:9 | 1920x1080 | jpg/webp | 视频模块使用 |

前端交付建议：
- 图片上线格式优先使用 webp，同时保留原始 jpg/png。
- 关键首屏图需要单独压缩和预加载。
- 所有图片预留宽高，防止页面布局偏移。

## 6. 产品截图采集规范

### 截图内容

优先采集：
- BIMCC 智能建造平台首页或项目驾驶舱。
- BIM+GIS 一张图。
- 项目进度、质量、安全、成本、资料等管理模块。
- 飞椽 Fyra 表单、流程、大屏、应用构建界面。
- 智慧工地设备接入和现场监管界面。
- 数字孪生运维驾驶舱。

### 截图要求

- 屏幕分辨率不低于 1920px 宽。
- UI 字体清晰，不出现浏览器调试栏。
- 所有客户敏感数据、手机号、身份证、账号、精确金额、内部系统地址需要脱敏。
- 不展示测试用户名、测试项目名、错误弹窗和未完成模块。
- 同一产品截图使用统一浏览器尺寸和缩放比例。
- 截图命名标注产品、模块和尺寸。

### 脱敏规则

可保留：
- 行业类别。
- 功能模块名称。
- 非敏感统计口径。
- 公开项目名称，前提是已授权。

需处理：
- 客户内部组织架构。
- 人员姓名、电话、身份证、账号。
- 未公开项目名称和位置。
- 合同金额、精确成本、内部审批意见。
- 系统内部 URL、IP、Token 或调试信息。

## 7. 案例素材采集规范

每个案例建议准备：

| 素材 | 必需 | 说明 |
|---|---|---|
| 案例封面图 | 是 | 项目现场、建筑外观、平台应用截图任选其一 |
| 项目图集 | 否 | 3-6 张，用于详情页 |
| 平台应用截图 | 是 | 展示筑云实际服务内容 |
| 客户 Logo | 否 | 需授权 |
| 项目基础信息 | 是 | 行业、地区、客户类型、服务内容 |
| 成果证据 | 待复核 | 仅展示可公开成果 |
| 授权记录 | 是 | 图片、客户名、Logo、案例公开范围 |

案例公开等级：

| 等级 | 展示方式 | 说明 |
|---|---|---|
| approved | 真实客户名、Logo、项目图可展示 | 最适合首页精选 |
| limited | 展示项目名或行业化标题，隐藏 Logo | 适合案例库 |
| anonymized | 使用“某大型项目”表达 | 可证明行业经验 |
| internal_only | 不公开 | 仅内部销售使用 |

## 8. 荣誉资质素材规范

采集字段：
- 证书或奖项名称。
- 颁发机构。
- 颁发年份。
- 有效期。
- 证书编号。
- 展示范围。
- 复核状态。

图片要求：
- 证书名称和机构可读。
- 不展示不应公开的编号或敏感信息。
- 过期证书不在首页展示。
- 首页只展示代表性资质，完整列表进入荣誉资质页。
- 同类证书使用统一裁切和背景。

命名示例：

```text
honor-cmmi-certificate-1200x1600.jpg
honor-high-tech-enterprise-certificate-1200x1600.jpg
honor-patent-smart-construction-1200x1600.jpg
honor-award-digital-construction-1200x1600.jpg
```

## 9. Logo 与合作伙伴素材规范

Logo 类型：
- 公司 Logo 标准版。
- 公司 Logo 深色背景版。
- 公司 Logo 浅色背景版。
- 合作伙伴 Logo。
- 客户 Logo，需授权。

格式要求：
- svg 优先。
- png 需透明背景。
- 不使用截图抠出来的模糊 Logo。
- Logo 墙只展示 Logo，不在 Logo 下方加行业小字。
- 不同 Logo 统一视觉高度，不强行拉伸。

授权要求：
- 客户 Logo 必须明确可用于官网。
- 合作伙伴 Logo 确认展示范围。
- 未授权 Logo 不进入首页。

## 10. PDF 与资料下载规范

资料类型：
- 产品介绍 PDF。
- 解决方案 PDF。
- 案例集。
- 白皮书或行业洞察。
- 公司宣传册更新版。

字段要求：
- 资料标题。
- 文件版本。
- 发布日期。
- 是否需要留资。
- 封面图。
- 下载权限。
- 关联产品或方案。

命名示例：

```text
download-bimcc-platform-introduction-2026.pdf
download-fyra-product-brief-2026.pdf
download-smart-site-solution-2026.pdf
download-case-collection-digital-construction-2026.pdf
```

## 11. Alt 文案规范

Alt 文案写真实内容，不堆关键词。

示例：

| 素材 | 推荐 Alt | 不推荐 |
|---|---|---|
| 平台截图 | BIMCC 智能建造平台项目驾驶舱截图 | 智能建造 BIM 数字孪生 智慧工地 |
| 案例封面 | 某交通基础设施项目现场图 | 大型项目高清图片 |
| 飞椽截图 | 飞椽 Fyra 表单与流程配置界面 | 低代码平台截图 |
| 证书图片 | 筑云科技 CMMI 认证证书 | 荣誉资质 |
| 联系二维码 | 筑云科技官网咨询二维码 | 微信二维码 |

规则：
- 每张关键图片必须有 alt。
- 装饰性背景可留空 alt，但不建议关键内容做成背景图。
- 未授权案例不要在 alt 中写真实客户名。

## 12. 素材交付表

建议用表格或 CMS Asset 模型跟踪：

| 字段 | 示例 | 说明 |
|---|---|---|
| asset_id | hero-platform-dashboard | 唯一 ID |
| file_name | hero-platform-dashboard-2400x1350.jpg | 文件名 |
| asset_type | 产品截图 | 素材类型 |
| page_usage | 首页 Hero | 使用位置 |
| source_owner | 产品部 | 来源负责人 |
| rights_status | approved | 授权状态 |
| public_allowed | yes | 是否可公开 |
| need_desensitize | no | 是否需脱敏 |
| alt_text | BIMCC 智能建造平台项目驾驶舱截图 | 替代文本 |
| crop_focus | center | 裁切焦点 |
| reviewer | 市场负责人 | 审核人 |
| review_status | pending | 审核状态 |
| notes | 用于首页首屏主视觉 | 备注 |

## 13. 素材审核流程

建议流程：

1. 市场和产品按 P0 素材清单收集。
2. 项目负责人确认案例、客户名、项目图公开范围。
3. 产品或研发完成平台截图脱敏。
4. 设计师根据比例裁切并生成网页版本。
5. 内容负责人补充 alt、标题、说明和来源。
6. 法务或管理层确认高风险素材。
7. 前端或 CMS 负责人上传并绑定页面字段。
8. 上线前抽查首页、案例页、产品页和荣誉资质页。

不得跳过：
- 客户 Logo 授权。
- 平台截图脱敏。
- 证书有效期复核。
- 联系方式和二维码复核。

## 14. 首页首批素材包

为保证首页视觉稿和开发可继续推进，建议先完成以下包：

```text
01-brand-logo-pack
02-home-hero-platform-visual
03-home-product-screenshots
04-home-case-covers
05-home-honor-proof
06-contact-qrcode-and-info
```

每个素材包应包含：
- 原始文件。
- 网页裁切版。
- 文件命名表。
- 授权状态。
- alt 文案。
- 使用页面和模块。

## 15. 上线前素材验收

- 首页首屏主视觉真实、清晰、已脱敏。
- 产品截图可读，不出现测试数据和敏感信息。
- 首页案例图已完成授权或匿名处理。
- 客户 Logo 和合作伙伴 Logo 授权范围明确。
- 荣誉资质图片名称、机构、年份和有效期已复核。
- 所有关键图片有 alt 文案。
- 二维码可扫码，指向正确账号或咨询入口。
- 图片尺寸合理，移动端裁切不遮挡核心内容。
- 所有 PDF 能打开，文件名和版本正确。
- 不可公开素材没有进入前端项目或 CMS 发布状态。
